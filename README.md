# BlockShotsStop 0.10

Приложение на C# и .NET MAUI для Android 8 и новее. APK собирается для ARM64.

## Блокировка коротких видео

1. На главном экране нажмите «Настроить и включить защиту». В специальных возможностях Android выберите BlockShotsStop и разрешите службу.
2. Вернитесь в приложение. Когда Android подключит службу, на главном экране появится статус «Защита активна». Здесь же можно выбрать приложения для блокировки.
3. Откройте короткую ленту. При совпадении правила служба нажмёт «Назад». Если тот же короткий экран остаётся активным через 900 мс, служба отправит команду «Домой».

Если Android сообщает об ограниченной настройке, нажмите «Android не даёт включить службу?» на главном экране. Приложение покажет, где найти эту настройку, и сможет открыть системные сведения о BlockShotsStop.

Поддерживаются YouTube Shorts, клипы ВКонтакте и VK Видео, Instagram Reels и видеолента TikTok. Для Instagram и TikTok правила проверяют видимый плеер, который занимает большую часть окна. TikTok может открываться сразу в видеоленте. В этом случае блокировка сработает при запуске TikTok. Правило TikTok основано на разметке версии 47.9.3 приложения `com.zhiliaoapp.musically`. Изменения интерфейса могут повлиять на распознавание.

## Диагностика

Откройте «Диагностика распознавания», выберите приложение и нажмите «Копировать отчёт». Отчёт показывает версию приложения, последнее событие и структуру экрана без произвольного текста элементов. Настройки, счётчик команд выхода и отчёты хранятся локально. Приложение работает без доступа к интернету.

## Структура проекта

- `MainPage.xaml` и `DiagnosticsPage.xaml` описывают экраны MAUI.
- `Platforms/Android` содержит службу специальных возможностей, манифест и доступ к настройкам Android.
- `ShortsDetector.cs` и `ClipScreen.cs` содержат правила распознавания. Их проверяет консольный проект `Checks`.

## Сборка и проверки

Целевая платформа приложения — .NET 10 for Android. Для сборки нужны SDK с нагрузками Android и MAUI, Android SDK с платформой API 36.1 и JDK 21. Сборка проверена на .NET SDK 11.0.100.

Из каталога проекта выполните:

```powershell
dotnet build BSS.csproj -c Release
dotnet run --project Checks/Checks.csproj
```

Если отсутствует рабочая нагрузка, выполните `dotnet workload restore BSS.csproj`. Если Android SDK или JDK не находятся автоматически, передайте `-p:AndroidSdkDirectory=<путь к Android SDK>` и `-p:JavaSdkDirectory=<путь к JDK>`. Готовый APK появится в `bin/Release/net10.0-android36.1/android-arm64`.

Для обновления установленной версии APK должен быть подписан тем же ключом. Проект сохраняет идентификатор `org.nikita.shortsguard`, имя службы и ключи локальных настроек. После обновления проверьте подключение службы, сохранённые переключатели и поведение обычных и коротких видео на устройстве.
